# TounsiWave Support

TounsiWave is an ad-free radio player for Tunisian and other curated radio stations.

## Get Support

To report a problem, request help, or ask a privacy question, open a public issue:

https://github.com/SWdev14/tounsiwave-support/issues

Please do not include passwords, payment information, precise location, or other sensitive personal information in an issue.

## Privacy

Read the TounsiWave privacy policy:
